# victor | Next.js

Projeto web desenvolvido com [Next.js](https://nextjs.org), React e Tailwind CSS.

## Páginas do Projeto

- **Home (`/`)**: Página inicial com apresentação do projeto e cartões de acesso rápido.
- **Sobre Nós (`/sobre`)**: Informações sobre os objetivos do projeto e tecnologias empregadas.
- **Produtos (`/produtos`)**: Catálogo demonstrativo com cards estilizados e preços.

## Como Executar

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para visualizar.

## Tecnologias

- Next.js 16 (App Router)
- React 19
- Tailwind CSS
- TypeScript
